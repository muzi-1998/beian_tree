# Stage B figure contract

Backend: Python, matplotlib. Figures are methods/Extended Data evidence, not the
five future-performance figures proposed for the unopened 108-day period.

## H1: Temporal scope and information availability

Claim: identical timestamp strings need not represent the same information set.
Panel a shows the historical replay span, absolute D5 reference endpoint and
sealed later-period interval. Panel b compares the minimum source-window closure
delay relative to each output's label. These delays exclude computation and
upstream transform latency. Archetype: quantitative grid, timeline-led.

## H2: Future-tail dependence and its historical numerical impact

Claim: historical numerical reproducibility alone does not establish causal
validity. Panel a is a deterministic missing-run counterexample for D2. Panel b
shows the deterministic D4 change-point score counterexample. Panel c shows all
seven historical pairs' changed CP-score fractions. Panel d shows low-tail flips
on common evaluable support, with original other subscore values and gates held
fixed. Panels a/b are synthetic contract tests; c/d use the old study period.
No new-period observations, scores or performance were used to select cases.
Archetype: quantitative grid, counterexample plus consequence.

Counts are deterministic finite-dataset comparisons, not independent replicates.
No p values, inferential confidence intervals or causal operating-condition
claims are appropriate here. Row denominators and all paired counts are exported.
All seven pairs and the complete predefined synthetic case traces are retained.
Only the identical D2 synthetic DO_1_4 trace is drawn; the test covers all14 and
the full channel-wise table is included. This is a stated display reduction,
not exclusion from analysis. Unknown future-prefix entries remain blank.

Export: 183 mm, Arial7pt with8pt bold `(a)` labels, editable SVG/PDF, 600dpi
TIFF and PNG preview, CSV/Parquet source tables and a source workbook. No log
pseudocounts, smoothed values, cut numerical baselines or fabricated performance.
Open axes use outward ticks; full boxed categorical raster has inward ticks only
on labelled sides. Black text, redundant marker/line encoding and a restrained
blue/vermillion/neutral palette. No labels over data or decorative card framing.

The official [Nature specifications](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)
were checked2026-09-05: readable sans-serif text, explicit axes/units, accessible
colour and editable vector exports. Journal requirements do not certify science.
