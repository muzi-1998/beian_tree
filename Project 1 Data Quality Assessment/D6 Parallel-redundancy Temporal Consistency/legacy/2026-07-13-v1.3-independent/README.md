# Frozen v1.3 comparison inputs

This directory preserves the pre-restoration v1.3 outputs used by the
three-version sensitivity analysis. The package used pair-specific quantile
mapping from the first 70% of D2-non-veto windows, a 24 h half-window change
proxy, no D1/D7 arbitration, and a 2 h event rule.

These files are comparison evidence only. They are not the current D6 results.
